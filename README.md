# Auto-Project-Directory
A simple TUI for creating folders and initial setup steps for a project. Built using Textual


![preview](https://github.com/Shades84/Auto-Project-Directory/blob/main/Screenshot.png?raw=true)

# Installing
1. download the repository
2. install textual per the instructions on their [site](https://textual.textualize.io/)

# Running
1. run `textual main.py`
2. type in the new project name in the top field. This becomes the folder name
3. select what subdirectories you'd like to add
4. select other options as well (PS. when selecting make note, it will create a blank markdown file with a clickable link to your folder)
5. press create button. Your folder will be created in whatever folder you have set in the settings panel

# Customizing
1. go to the settings tab and add/remove any directories you'd like to select from in the future
2. change the default paths for your projects and notes
3. hit the save settings button. This will also save your current theme
